# 固定剧情样例人工复核

以下八例是隔离的文字评阅材料，不是当前游戏人物、地点、价格或已发生事件。评阅者为本批交接作者；这是有限样例的人工判断，不是独立盲评或自动文学质量证明。真实事务/可见性/因果/重写的硬检查另见step18故事用例。

| 场景 | 固定片段 | 自由回应及边界检查 |
|---|---|---|
| 求救者 | 通道传来断续敲击。门后的旅人说同伴还没回来，想请人确认安全，但他也说不清最后见面的时间。指挥官，可以先问清经过。 | 玩家可询问、查证、离开或另提办法；未知去向不写成死亡；不自动派舰 |
| 贫困家庭 | 桌上摊着修补过的工作服。母亲把账纸推近，低声说只想让孩子先吃上一顿，账纸上有几笔还没核实。 | 可核实、帮助、转介或拒绝；不给未经证实的贫困金额；承诺不等于已支付 |
| 逃亡研究者 | 来客坐在能看到出口的位置，始终没有打开手提盒。他声称资料属于自己，却拿不出完整授权记录。 | 口述归为声称；可索证或终止谈话；不凭身份创造科技优势或秘密组织 |
| 商人议价 | 商人掀开货箱一角，先问规格和交付地点，随后停下来等你的条件。纸上那道旧报价已经划掉。 | 自由议价；没有有效新报价就继续澄清；报价不触发付款或库存增加 |
| 废弃设施 | 手电扫过积尘的门框，内侧有一道较新的擦痕。设备是否还能供电尚不清楚。 | 可观察、取证或撤离；擦痕不是敌人证据；不直接写成发现高级遗产 |
| 普通员工日常 | 交班的人揉了揉肩，把没写完的记录递过来，说今天最麻烦的是反复找错工具。 | 可聊需求或结束话题；日常困难不升级成阴谋；建议仍可拒绝 |
| 无战斗结案 | 双方确认已交回借用物品，桌上的清单逐项对齐。对方收起纸张，说此事到这里结束。 | 没有虚构战果或奖赏；关闭后不自动重启；实际清单/资金须与存档相符 |
| 玩家拒绝帮助 | 对方听完你的拒绝，停了一下，把伸出的手收回去，说会再想别的办法。通道仍可以正常离开。 | 拒绝可结束当前请求；不强制菜单、惩罚或花费；后果须有证据与必要的新授权 |

八例均保留环境、人物目标和不确定性，允许自由表达，没有擅自给出资金、战力或已提交效果。主叙述使用副官口吻并在需要决定时停下。它们故意采用不同诉求与反应；有限片段尚不足以量化长期剧情重复率，也不证明任意自然语言不会夹带错误事实。运行时偏好与最近桥段排序的改善、关闭和撤销另有固定输入测试。
