# VOYAGER V14.66 加速说明

本版已修改并验证源码，来自本次提供的V14.65完整包与匹配Guard。Engine 2.73.0 → 2.74.0，Guard维持2.23.0原实现和协议4。升级是零时间维护，没有替玩家推进游戏。

## 实测速度

| 项目 | V14.65 | V14.66 | 提速 |
|---|---:|---:|---:|
| CLI取得剧情准备＋概览＋时间计划 | 2.321秒 | 0.725秒 | 3.20倍／耗时减少68.8% |

表内为本机顺序运行、不带性能分析器的墙钟时间，包含Python/JSON处理；复制测试目录、构造合成场景和模型生成等待不计入。工作流、推进和回合写入各3次取中位数，热进程只读组合5次；首次冷CLI读各1次单列在原始报告，不混作中位数。操作系统页缓存未清空，不代表冷磁盘速度。所有写入在独立SYNTHETIC副本中执行。真实ChatGPT工具传输、模型生成时间及真实端到端文学质量未测；不能把后端倍数当成整个聊天的保证。

## 慢在哪里，如何修改

1. 正常查询分散在storyprepare、roundcontext、routineplan三个入口，需要重复进入读锁、哈希、安全目录检查和输出投影，CLI还要重复启动和加载约1.9MB引擎。新增playcontext和HostSession.context，一次取得剧情准备、余额/任务/场景概览及可选时间计划，使用同一存档身份和一个读取边界。
2. 19个压缩历史段展开后的原文共49,075,105字节。请求之间会重复解码和构造不可变对象。新增进程内有界LRU，仅缓存已核验的不可变历史解码；键包含真实档案内容SHA、完整记录、引擎版本和解释器信息。每次仍重新读取/哈希原档案；不是凭文件时间戳或文件大小信任旧结果。缓存按64MiB解码原文预算、32条目淘汰，此预算不是整个进程内存上限。
3. 每次读取要检查440余个开发文件；旧目录边界算法对每条路径重复构建并检查多层parents。改为一次构建祖先列表、每个边界读取lstat；事务依赖检查共享本次读取的祖先模式。源文件内容哈希、目录形状、权限及符号链接检查继续保留。
4. 经营查询直接调用API时缺少最外层SnapshotContext，容易先做一次就绪检查，再独立做一次源验证。补齐作用域；完整校验也在适配的只读快照里共享解析。确认纯读的验证器改读不可变视图，公共可变读取仍返回独立副本。
5. V14.65的新增模块清单缺少name/import/export及旧解析器capture信息，分模块开发加载器会失败。补齐11b、45模块契约和capture；新增46_fast_play模块后重新构建，已核对开发源码与生成引擎的接口结果一致。README旧指向V14.61也已改为当前指南。

最终ZIP冷启动还修正了旧版硬编码指南；改为读取manifest.current_guide，去掉与five_balances重复的两个浮点余额显示，启动后续入口优先playcontext，保留3500字节硬预算与五项精确余额。性能计时后的这项启动显示修正没有再次计时；原计时源码SHA及最终源码SHA均在原始报告中记录，所测读取、剧情提交与日结热路径未再修改。

未删去锁、真实授权、风险屏障、资金校验、原子提交、故障恢复或独立叙事复核。没有自动批准宿主指令，没有把一次用户回合拆成几个持久提交，也没有把多个不同用户回合合成一次提交。

## 怎样获得实际加速

首次在新环境恢复一次：`python SAVE_GUARD_V14.66.py --resume`。之后正常回合优先：

```bash
python engine.py playcontext --intent "玩家本轮原话"
```

已有场景时补上真实的`--scene-id`、`--actor-id`。需要时间规划时加`--until`，例如8363-12-12T08:00:00；该参数只生成计划，不执行推进。准备结果NO_OPEN_SCENE不意味着可以自动复活旧事件；预算不足仍必须补足材料。

使用可信嵌入宿主时，复用同一个HostSession的context/submit，保留实际用户指令核验和玩家正文复核。缺少宿主接线时仍使用原边界；本版没有声称已在ChatGPT安装自动宿主、后台服务或跨工具常驻进程。

把同包`development/游戏项目指令_加速版.txt`加入游戏项目指令，明确优先批量读取、已授权普通步骤不重复确认、直接衔接连续行动、常规路程/等待简写、按合理实际耗时推进。不要每回合额外重跑Guard全检查、selftest、全量源码分析和导出包；需要恢复、发现损坏和正式交付时仍做对应完整检查。

剧情加速是操作规范及上下文提示。正式存档的玩家偏好没有被伪造的授权记录覆盖；AI文学表现和时长仍取决于实际运行环境。
